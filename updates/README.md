# Research updates

This directory is reserved for dated updates that remain directly connected to the Lesieutre-Litt blow-up question.

## 2026-09-08

- Initial short manuscript completed.
- Main result: a finite-index subgroup of the automorphism group of the iterated blow-up descends faithfully to the starting variety in the smooth complex-projective, codimension-at-least-three setting.
- The Hessian discriminant of the top intersection form is the key numerical invariant used to detect the pullback hyperplane.

Further updates will be added without rewriting the history of the initial manuscript.
